\begin{center}\vspace*{6mm}{\LARGE Arrowhead support systems in Rust}\par\vspace{4mm}{\large Development implementation and interface catalogue}\end{center}
\begin{abstract}Fifteen active support-system profiles from the local modified Java tree have native Rust executables. This catalogue distinguishes implemented behavior, explicit unsupported interfaces and unqualified integrations. It is NOT a claim of complete v5.2.2 Java interchangeability.\end{abstract}
\ArrowheadBox{Do not replace working clouds.}{Onboarding provisioning, federation/tunnel data planes and SysMonitor broker workers are not implemented. Other profiles have documented semantic gaps. No live cloud was changed.}

\section{Blacklist}
\subsection{System overview}
Native Rust development profile for local Java source \path{Blacklist/}. One independently configured executable, identity, port and state file per role. No Java, Go or Python process implements the service. Some essential operations are explicitly unavailable.
\subsection{Design and trust boundaries}
Tokio/Hyper/Axum with rustls enforces mutual TLS. Certificate chain, validity, local CN/profile and startup-configured optional CRLs are checked. CRLs need process restart to refresh; without CRLs no revocation enforcement is claimed. Tokens are verified with Authentication and bound to the TLS identity. Business calls require ConsumerAuthorization; management requires a verified sysop or explicit broad whitelist. CA provisioning instead applies Java-style named certificate-principal rights. Outbound authorities are pinned to expected CN/profile before credentials are sent, in addition to chain, SAN and time validation.
\subsection{Persistent state}
Independent locked atomic JSON replaces SQL. Clone/validate/fsync/rename commits prevent partially published local transactions. Rename is the commit point; directory-sync failure is an uncertain durable commit, not a rollback. Owner-only keys/password files are separate. Network effects are not distributed transactions; interrupted starts and bridge operations require reconciliation. No automatic Java state import, clustering or deployment is delivered.
\subsection{Implemented behavior}
Create/revoke, expiry/check/lookup, filtered queries
\subsection{Open release gates}
Full normalization and historical query parity. All systems remain development profiles, not certified interchangeable Java replacements. See \path{COMPATIBILITY.md} for detailed DTO fields and restrictions; the Java sources remain the authoritative contract.
\subsection{Produced and consumed services}
Advertised implemented HTTPS definitions: \path{blacklistDiscovery}, \allowbreak \path{blacklistManagement}, \allowbreak \path{echo}, \allowbreak \path{generalManagement}.\par
Authorities consumed as applicable: Authentication, ServiceRegistry, ConsumerAuthorization and explicitly configured pinned adapter/provider origins. Only implemented operations are registered. Service versions are 1.0.0 except Gatekeeper/GateTunnel 5.2.2. No AMQP sysMonitor.observe implementation is advertised.

\section{Contract details}
Blacklist create uses \path|entities[{systemName,expiresAt,reason}]|; queries \path|pagination,systemNames,mode,issuers,revokers,reason,alivesAt|; check is a boolean; query is \path|count/entries|; remove uses \path|names| query values.\par\medskip
Configuration store uses \path|systemName,fileName,contentType,data| (base64); response adds \path|id,size,createdAt,updatedAt|; list is \path|count/data|; raw response uses stored MIME type. Owner checks apply to non-management APIs.\par\medskip
Historian PUT is a SenML array; accepted records require one \path|v/vs/vb/vd/s| value. GET supports numeric epoch \path|from,to,count,signals|. Filtered output reinserts \path|bn/bt| context. Unsupported base-value/sum semantics and \path|signalCount| return501. Proxy uses registry operation metadata and explicit pinned provider origins.\par\medskip
Time returns \path|epoch,epochMs,tz,dst,trusted,offsetMs,timeSource,lastCheckTime|; source is explicitly \path|system-clock-unverified|.\par\medskip
AIGym samples use \path|model,features,target|; predictions \path|model,features,neighbours|. Missing coordinates are zero; default model is \path|default|, k defaults3 and clamps to available samples.\par\medskip
Event subscription: \path|eventType,notifyUri,matchMetadata,metadataFilter,startsAt,expiresAt|; publish: \path|eventType,payload| (string), \path|metadata,timestamp|; notification includes \path|sourceSystemName|; accept response \path|matchedSubscriptions,acceptedDeliveries|. Three attempts; an in-flight callback may race unsubscribe. Callbacks can return an empty body; nonempty replies currently need valid JSON.\par\medskip
QoS request: \path|providers,configuration{metricNames,metricWeights,timeWindow,threshold}|; lower weighted scores rank first, missing metrics rank last/drop. Measurement adapter returns \path|systemName,metricGroup,timestamp,current|.\par\medskip
Plant documents: \path|plantDescription,active,include| numeric IDs, \path|systems[{systemId,systemName,ports}]|, \path|connections[{consumer:{systemId,portName},producer:{...}}]|. Only one active; cycles/dangling ports rejected. Alarm PATCH uses \path|acknowledged| boolean.\par\medskip
Choreography plans use \path|name,firstActionName,actions|; actions \path|name,nextActionName,firstStepNames,steps|; steps \path|name,quantity,serviceRequirement,staticParameters,nextStepNames|. Only one action/step profile executes.
